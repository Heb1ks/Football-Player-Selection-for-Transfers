# Проверка небольших исправлений интерфейса

Изменения подготовлены и технически проверены 23 октября 2026 года с помощью AI. Независимый review участника ещё не выполнен. Версия `prob-period-1` не менялась.

Что изменилось:

1. Reset очищает поиск по имени вместе с фильтрами.
2. Во время загрузки экспорт недоступен. Ответ от устаревшего запроса не подменяет результаты и параметры CSV.
3. Повреждённые и повторяющиеся записи shortlist пропускаются при чтении из браузера.
4. Удаление кандидата и очистку shortlist можно отменить кнопкой Undo. Пустой список нельзя повторно очистить.
5. Кнопки сохранения сообщают текущее состояние. Добавлены переход к содержимому с клавиатуры, видимая рамка фокуса и подпись области результатов.
6. На узком экране таблица прокручивается внутри своей области и не растягивает всю страницу.

Как проверить вручную:

1. Запустить `.venv/Scripts/python.exe app/server.py`, открыть http://127.0.0.1:8765.
2. Ввести `NoSuchPlayer123` в поиск: число кандидатов равно нулю, Export CSV недоступен. Нажать Reset: поиск пустой, кандидаты снова показаны.
3. Открыть профиль игрока и сохранить его. Кнопка должна смениться на Remove from shortlist; после Escape звёздочка в таблице отмечена.
4. Открыть My shortlist, нажать Clear shortlist и Undo. Карточки и счётчик должны восстановиться. Проверить также удаление одной карточки.
5. Проверить переход Skip to main content клавиатурой и закрытие профиля клавишей Escape.
6. При ширине браузера около 390 px проверить горизонтальную прокрутку таблицы. В проверенном браузере ширина страницы совпала с шириной доступной области, а таблица прокручивалась отдельно.

Автоматические проверки:

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
node --test tests/frontend.test.cjs
```

Локально прошли 11 проверок Python и 6 проверок JavaScript. Проверки JavaScript покрывают повреждённое хранилище, дубликаты, ответы запросов в обратном порядке, ошибку загрузки, пустой поиск и восстановление очищенного shortlist. Запуск JavaScript-проверок добавлен в конфигурацию CI. Результат удалённого запуска нужно смотреть в GitHub Actions для соответствующего коммита.

Для review нужно прочитать изменённые файлы, выполнить проверки и записать, что именно проверено и какие замечания найдены. Само наличие подготовленных изменений не подтверждает личное авторство проверяющего.
