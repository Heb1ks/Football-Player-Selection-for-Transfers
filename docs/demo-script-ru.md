# Демонстрация TransferLens за 5 минут

1. Запустите `./start.ps1`, откройте http://127.0.0.1:8765. Объясните: это ранний прототип диплома на реальных исторических данных. Исследовательское ядро взято из собственной командной работы RMT, интерфейс и интеграция добавлены для диплома.
2. Покажите 781 трансфер и 242 тестовых кандидата. Обучение: 2018–2021, валидация: 2022, тест: 2023–2024. Один игрок встречается только один раз.
3. Выберите summer 2023, Attack, maximum age 25. Нажмите Find candidates. Балл — прогноз голов плюс передач на 90 минут в первом сезоне нового клуба. Это не вероятность удачного трансфера и не общая полезность игрока.
4. Откройте профиль Rasmus Højlund. Покажите даты последних входных данных и разницу между прежним GA90, прогнозом и фактическим результатом. Целевой результат не передаётся модели.
5. Сохраните двух игроков через ☆. Откройте My shortlist и сравните их по одной позиции. Список хранится только в текущем браузере. Вернитесь и выгрузите CSV.
6. Выберите другое Destination context и RF + club formations. Объясните, что это исследовательский сценарий: смена схемы не доказывает причинного эффекта перехода в клуб. При таком сценарии система не показывает наблюдавшийся итог как истинный для нового клуба.
7. На Model evidence покажите четыре baseline/model результата. RF с признаками игрока практически равен простому прогнозу по прежнему GA90. Добавление номинальной схемы не улучшило тестовый RMSE. Это отрицательный результат, а не ошибка, которую надо скрывать.
8. Откройте Project board и любую задачу с критериями и файлами. Покажите репозиторий, реальные issues и историю. Не утверждайте, что один сегодняшний пакет доказывает длительную работу или вклад каждого участника.

Ответы на вероятные вопросы:

- Почему Random Forest? Небольшая табличная выборка, воспроизводимость, работа на CPU. Сравнение с persistence уже выполнено; превосходство над ним пока не установлено.
- Что значит RMSE 0.207? Корень средней квадратичной ошибки в единицах GA90 на 242 тестовых трансферах. Это не 79% точности и не персональный доверительный интервал.
- Что с защитниками? Они доступны в данных, но GA90 плохо отражает их вклад. Основной сценарий демонстрирует атакующих игроков; ролевые цели — следующий этап.
- Что делаете дальше? Реальные обсуждения с пользователями, отзыв руководителя, проверка требований, признаки с датой доступности, работа с несыгравшими трансферами и более строгая валидация.
- Готово ли к сдаче? Прототип и аналитическая основа готовы к обсуждению. Подтверждение пользователей, отзыв, индивидуальные коммиты и review должны быть добавлены фактически.
